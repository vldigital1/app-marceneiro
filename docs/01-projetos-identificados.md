## ⚠️ Pontos de atenção de direitos

1. **Armário de banheiro (Studio 1202)** — o PDF traz aviso explícito de "todos os direitos reservados, comercialização vetada". Para E1/E2 uso só o *tipo* genérico (armário 60 cm com espelho / gabinete suspenso), com medidas e sistema de montagem próprios. Se preferir, removo E1/E2 do lançamento.
2. **Guarda-roupa** — é manual de fabricante com marca registrada. A1 será um projeto próprio de guarda-roupa 5 portas; não uso nome, código nem layout do fabricante.
3. **+48 projetos** — tradução automática de planos do Woodworking for Mere Mortals (marcas "WWMM", "ParaMereMortals.net"). Só o tipo de móvel foi aproveitado.
4. **Nenhuma imagem** dos PDFs será usada. As miniaturas que gerei para identificar os títulos ficaram só na pasta temporária da sessão, fora do projeto.
